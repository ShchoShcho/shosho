# Специфікація архітектури системи та моделі даних

Актуальна специфікація: [архітектура, SQLite, структура проєкту та ERD](../architecture.md).

30.10.2026 специфікацію звірено з реалізацією. PostgreSQL свідомо замінено локальною SQLite; шкала оцінювання — 1–5. Окремої таблиці статусів і запланованих репозиторіїв наразі немає. Повний перелік реалізованого та невиконаних вимог наведено в [аудиті відповідності](../compliance-audit.md).
