# Перевірка злиття гілок

Перевірено локальну історію `develop` до `3c7cdb1`, включно з комітами фіч #24–#29 та наявними посиланнями на вихідні гілки. Віддалені посилання не оновлювалися; перевірка не охоплює неопубліковані зміни інших розробників.

## Знайдені втрати та несумісності

| Місце | Причина та виправлення |
| --- | --- |
| Початкова SQLite-міграція | У `611b4a5` видалено `20261008185827_InitialCreate` і додано повторне створення таблиць після міграцій тегів. Відновлено старий ID; новий ID збережено як крок узгодження, без повторного створення таблиць. |
| Міграції тегів | Змішані PostgreSQL і SQLite, паралельні `Tag`/`Tags`, `MediaItemTag`/`ItemTag`, повторний унікальний індекс. Узгоджено SQLite-схему, додано перенесення тегів і зв’язків перед видаленням застарілих таблиць. Прибрано повернуту залежність Npgsql. |
| Snapshot EF | Незакриті блоки, дублікати полів, скалярні `Tags`/`Review` поверх навігацій. Відновлено snapshot і додано міграцію `ReconcileMergedFeatures` для типу медіа, оцінки та старих назв статусів. |
| Модель і ViewModel | Повторні методи фільтрації та зміни статусу, невизначена `title`, змішані швидке додавання й модальний діалог. Залишено одну узгоджену реалізацію. Локальне видалення дубльованих скалярних `Tags`/`Review` збережено. |
| Вікно додавання | `5bd506e` викликає `AddItemWindow`, але не містить його файлів. Це неповна вихідна фіча, а не видалення в наступних злиттях. Додано вікно з перевіркою назви, тегів і оцінки. |
| Сітка й обкладинки | У `3c7cdb1` сітку замінено списком без обкладинок. Повернуто картки з постерами, збережено кешування та доповнено їх статусами, тегами й відгуками. |
| Пошук за тегами | Поле пошуку зникло з XAML; різні фільтри перезаписували один одного. Повернуто пошук і спільну фільтрацію за тегом та статусом, включно зі скиданням до «Усі». |
| Відгуки | XAML посилався на відсутні `ToggleReviewSectionCommand` і `IsReviewSectionOpen`, перевіряв застаріле «Завершено». Відновлено відкриття редактора, сповіщення WPF, збереження й оновлення одного відгуку на картку. Порожня оцінка дозволена. |
| Розмітка | Основний вміст потрапляв у рядок висотою `5*` замість основного `243*`. Прибрано помилковий поділ; список карток займає доступну висоту. Селектор рейтингу під’єднано до сортування. |

У доступній історії інших видалених файлів коду не знайдено. Напис `open-detail-window` вказує на той самий коміт, що й `add-item-and-review`; окремої реалізації вікна деталей там немає. Категорії бічного меню вже були декоративними елементами без команд — їхня логіка не загубилася в цьому злитті.

## Перевірки

```powershell
dotnet build ShoSho.slnx --disable-build-servers -m:1
dotnet run --project tests/ShoSho.SqliteSmoke --no-build
dotnet run --project tests/ShoSho.UiSmoke --no-build
```

SQLite-перевірки використовують окремі тимчасові бази: створення, повторні міграції, відповідність snapshot, CRUD, Unicode, UTC, оновлення зі старої початкової схеми, альтернативної початкової схеми, проміжних тегів і відгуків. Перевіряється збереження старих записів, тегів та відгуків, нормалізація статусів і каскадне видалення відгуку.

WPF-перевірки виконуються на STA-потоці без показу вікон: завантаження XAML, спільні фільтри, зміна статусу, створення та оновлення відгуку, сортування, повторне використання українських тегів і поля вікна додавання. Візуальний огляд та ручний прохід усіх дій мишкою не виконувалися.

Робочу базу користувача не відкривали й не змінювали. Історичні міграції довелося виправити, оскільки їхня сукупна послідовність була неробочою. Оновлення перевірено на відтворених схемах із репозиторію; вручну змінені бази можуть відрізнятися. Зворотне розділення об’єднаних тегів не підтримується: downgrade через `AddTagsTable` завершується явною помилкою замість втрати зв’язків.
